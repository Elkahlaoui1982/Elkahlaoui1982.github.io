Profile

About

I am an independent security researcher working across bug bounty programs, vulnerability disclosure programs and source-driven application-security research.

What I research

My strongest recurring track is authorization: cases where a user is blocked in one interface or role but can still reach the same privileged effect through an alternate endpoint, integration, stale state, delegated action or cross-tenant object reference.

I also work on application logic, API security, identity transitions, integrations, AI-agent boundaries, cloud/data systems and protocol-level security when the impact can be reproduced cleanly.

How I work

Controlled accounts, separate sessions, source review, local or VPS labs, minimal canaries, server-side verification and reproducible evidence. I prefer proving the boundary failure rather than inflating impact from a UI-only symptom.

Principles

Research standards

01Evidence before severity claims
02Separate roles and sessions
03Minimal impact reproduction
04Respect program scope
05Private details stay private
